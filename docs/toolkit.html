Toolkit

Common synth techniques, each built from a few partials components: recording and playing a sample, a basic synth voice, and a delay.

Each example is the inside of a module: its members, onSampleRateChange() and process(). To use one, draw a panel with the controls listed, generate the module as in the tutorial, then paste the code into struct YourModule : Module. Each id becomes ID_PARAM, ID_INPUT or ID_OUTPUT in the code. Use configParam for the knobs with the range given, and configButton for buttons.

Recording and playing a sample

#include "pt/core/math.h" · #include <vector>

Records an input into memory, then plays it back in a loop at any speed, including backwards. This is what Pure Data does with tabwrite~ and tabread4~.

How it works. partials has no table class: a std::vector<float> is the table. Recording writes one sample per call and moves on. Playback moves a read position by speed samples per call. Because the speed need not be a whole number, the position usually falls between two samples, so interpolateHermite() draws a smooth curve through the four nearest samples and reads the value in between.

Panel idKindRange
RECORDbutton (VCVButton)held to record
SPEEDknob-2..2, default 1
INinputaudio
OUToutputaudio
std::vector<float> table;   // the recording
size_t length = 0;          // samples recorded so far
float readPos = 1.f;        // playback position, in samples
bool wasRecording = false;

void onSampleRateChange(const SampleRateChangeEvent& e) override {
	// Room for 4 seconds. Allocate here, never in process(): asking for
	// memory on the audio thread can take long enough to cause a dropout.
	table.assign(size_t(4.f * e.sampleRate), 0.f);
	length = 0;
}

void process(const ProcessArgs& args) override {
	// 1. Record (tabwrite~). Pressing the button starts a new recording
	//    from the beginning; holding it keeps recording until the table is full.
	bool recording = params[RECORD_PARAM].getValue() > 0.5f;
	if (recording && !wasRecording) length = 0;
	wasRecording = recording;
	if (recording && length < table.size())
		table[length++] = inputs[IN_INPUT].getVoltage();

	// Hermite reads one sample before the position and two after,
	// so playback needs at least 4 samples to work with.
	if (length < 4) {
		outputs[OUT_OUTPUT].setVoltage(0.f);
		return;
	}

	// 2. Move the read head. 1 = original speed, 0.5 = an octave down,
	//    -1 = backwards. Keep it between 1 and length - 2 so all four
	//    samples it reads exist, wrapping at either end to loop.
	float start = 1.f, end = float(length - 2);
	readPos += params[SPEED_PARAM].getValue();
	if (readPos >= end) readPos -= end - start;
	if (readPos < start) readPos += end - start;

	// 3. Play back (tabread4~). size = 1 means readPos counts samples
	//    rather than running 0..1.
	outputs[OUT_OUTPUT].setVoltage(pt::interpolateHermite(table.data(), readPos, 1.f));
}

Notes.

  • The table stores volts as they arrive, so playback needs no rescaling.
  • Pd's tabread4~ uses a Lagrange curve rather than Hermite. Both read the same four samples and sound much alike, though Hermite rings a little less around sharp edges.
  • The loop jumps from end to start, which clicks unless the recording starts and ends near silence. To smooth it, fade the first and last few milliseconds of the recording, or crossfade between two read heads.
  • To play the sample at a pitch, set the speed from V/Oct: speed = pt::semitonesToRatio(12.f * volts).

A simple synth voice

#include "pt/osc/basic.h" · "pt/filter/svf.h" · "pt/mod/envelope.h" · "pt/core/units.h"

The classic subtractive voice: a bright oscillator, a low-pass filter to take some of the brightness away, and an envelope that shapes each note when a gate arrives.

How it works. The envelope does two jobs. It sets the volume, which makes this its own VCA, and it opens the filter. That way a note gets brighter as it gets louder and darker as it fades, the way a plucked string or a struck piano key does. The ENV knob sets how far the envelope opens the filter beyond the CUTOFF setting.

Panel idKindRange

SUSTAINknob0..1, default 0.6

OUToutputaudio
pt::BasicOscillator oscillator;
pt::Svf filter;
pt::Envelope envelope;
float sampleRate = 48000.f;

void onSampleRateChange(const SampleRateChangeEvent& e) override {
	sampleRate = e.sampleRate;
	oscillator.init(sampleRate);
	oscillator.setShape(pt::BasicOscillator::SAW);
	filter.init(sampleRate);
	envelope.init(sampleRate);
}

// A 0..1 knob to a time from 1 ms to 4 s. Exponential, so the short times
// (where the ear notices small changes) get most of the knob's travel.
static float knobToSeconds(float k) { return 0.001f * std::pow(4000.f, k); }

void process(const ProcessArgs& args) override {
	// 1. Envelope. The setters are cheap, so read the knobs every sample.
	envelope.setAdsr(knobToSeconds(params[ATTACK_PARAM].getValue()),
	                 knobToSeconds(params[DECAY_PARAM].getValue()),
	                 params[SUSTAIN_PARAM].getValue(),
	                 knobToSeconds(params[RELEASE_PARAM].getValue()));
	bool gate = inputs[GATE_INPUT].getVoltage() >= 1.f;
	float env = envelope.process(gate);   // 0..1

	// 2. Oscillator: knob plus V/Oct input, both in octaves around C4.
	oscillator.setFrequency(pt::voltToHz(params[FREQ_PARAM].getValue() + inputs[VOCT_INPUT].getVoltage()));
	float saw = oscillator.process();

	// 3. Filter. Cutoff knob plus the envelope, on a 0..1 scale mapped
	//    exponentially to 20 Hz..20 kHz. Keep it below half the sample
	//    rate, the highest frequency the filter can be tuned to.
	float k = pt::clamp(params[CUTOFF_PARAM].getValue() + params[ENV_PARAM].getValue() * env, 0.f, 1.f);
	float cutoff = std::fmin(20.f * std::pow(1000.f, k), 0.45f * sampleRate);
	float q = 0.5f + 9.5f * params[RES_PARAM].getValue();   // 0.5 (no peak) .. 10 (ringing)
	filter.setFrequency(cutoff, q);
	float filtered = filter.process(saw).lp;

	// 4. The envelope as a VCA, then ±1 to Rack's ±5 V.
	outputs[OUT_OUTPUT].setVoltage(5.f * filtered * env);
}

Variations.

  • For a pluck, use envelope.setAd(attack, decay). It ignores how long the gate stays high.
  • For a louder, rounder resonance, put pt::softClip() after the filter: high q values can push the output above ±1.
  • For a softer, organic filter and VCA in one, replace steps 3 and 4 with a pt::LowPassGate.

A simple delay

#include "pt/fx/delay_line.h" · "pt/filter/one_pole.h" · "pt/core/math.h"

An echo with time, feedback and dry/wet mix controls.

How it works. A pt::DelayLine holds the last two seconds of sound. Each sample, the code reads the echo from time seconds ago, then writes the input plus some of that echo back in. The echo comes round again, quieter each time, which is what feedback means. Mix then blends the dry input with the echoes.

Panel idKindRange
TIMEknob0.01..2 seconds, default 0.4
FEEDBACKknob0..1, default 0.4
MIXknob0..1, default 0.3
INinputaudio
OUToutputaudio
pt::DelayLine line;
pt::OnePole timeSmoother;
float sampleRate = 48000.f;

void onSampleRateChange(const SampleRateChangeEvent& e) override {
	sampleRate = e.sampleRate;
	line.init(size_t(2.f * sampleRate) + 4);   // 2 s, plus a few samples for interpolation
	timeSmoother.init(sampleRate);
	timeSmoother.setFrequency(3.f);
}

void process(const ProcessArgs& args) override {
	float in = inputs[IN_INPUT].getVoltage() / 5.f;   // ±5 V to ±1

	// 1. Delay time, smoothed. A sudden jump in read position clicks; a
	//    smoothed one glides, and the echoes bend in pitch like a tape
	//    machine changing speed.
	float time = timeSmoother.process(params[TIME_PARAM].getValue()).lp;
	float delaySamples = pt::clamp(time * sampleRate, 1.f, 2.f * sampleRate);

	// 2. Read the echo from the past.
	float echo = line.readHermite(delaySamples);

	// 3. Write the input plus some of the echo back in. Feedback is capped
	//    below 1, so the echoes always die away, and softClip() keeps
	//    loud repeats from growing without limit: they saturate instead.
	float feedback = 0.95f * params[FEEDBACK_PARAM].getValue();
	line.write(pt::softClip(in + feedback * echo));

	// 4. Mix dry and wet, then ±1 back to ±5 V.
	float out = pt::crossfade(in, echo, params[MIX_PARAM].getValue());
	outputs[OUT_OUTPUT].setVoltage(5.f * out);
}

Variations.

  • For darker repeats, like tape or an analogue delay, put a pt::OnePole low-pass in the feedback path. Each echo is then a little duller than the last.
  • For a tape wobble, add a slow pt::SineOscillator and a pt::SmoothRandom to delaySamples, a few milliseconds' worth each.
  • For stereo ping-pong, use two lines and feed each one's echo into the other.
