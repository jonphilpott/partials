Effects

The effects built into Rings, Elements, Clouds and Plaits, as separate parts.

The stereo effects take float& left, float& right and process in place. The mono ones take a sample and return one. The delay-based effects allocate memory in init(), so call it from onSampleRateChange.

Reverb

#include "pt/fx/reverb.h" · from Rings, Elements and Clouds

A stereo plate-style reverb with a smooth, dense tail, and the same effect each of those modules has built in. Pick a module's tuning with a preset.

How it works. This is the "Griesinger" design from Jon Dattorro's 1997 paper:

  1. The input passes through four all-pass filters, which smear each sound into a dense spray of echoes.
  2. That feeds a figure-of-eight loop of long delays and more all-passes. Each half of the loop feeds the other, with a low-pass inside so highs die first, as in a real room.
  3. Left and right are taken from different halves, which gives a wide stereo image.
  4. Slow LFOs wobble some delay taps to blur metallic ringing.
CallRangeEffect
init(sampleRate, preset)Reverb::RINGS (brighter, shorter), ELEMENTS (larger; the default) or CLOUDS (smaller, denser).
setAmount(x)0..1Dry/wet mix.
setTime(x)0..1Decay: 0.5 is a small room, 0.9 a hall, 0.98 near-infinite.
setInputGain(x)0..1Level into the reverb. The modules used 0.2; keep it low, because the loop has a lot of gain.
setDiffusion(x)0..1How smeared the echoes are. Default 0.625.
setLp(x)0..1Damping: 1 is bright; lower values darken the tail faster.
clear()Silence the tail.
process(l, r)Stereo in, stereo out, in place. For mono input pass the same value as both.

The modules' own settings make good starting points:

  • Rings: amount 0.1–0.6, time 0.35–0.98, lp 0.3–0.9, all following its damping and brightness knobs.
  • Clouds: diffusion 0.7, time 0.35–0.98, lp 0.6–0.97.
pt::Reverb reverb;

void onSampleRateChange(const SampleRateChangeEvent& e) override {
    reverb.init(e.sampleRate, pt::Reverb::ELEMENTS);
}

void process(const ProcessArgs& args) override {
    float size = params[SIZE].getValue();
    reverb.setAmount(params[MIX].getValue());
    reverb.setTime(0.35f + 0.63f * size);
    reverb.setLp(0.3f + 0.6f * params[TONE].getValue());
    float l = inputs[LEFT].getVoltage() / 5.f;
    float r = inputs[RIGHT].isConnected() ? inputs[RIGHT].getVoltage() / 5.f : l;
    reverb.process(l, r);
    outputs[OUT_L].setVoltage(5.f * l);
    outputs[OUT_R].setVoltage(5.f * r);
}
// Shimmer-ish: pitch-shift the reverb's output up an octave and feed it back
float l = in + 0.3f * fbL, r = in + 0.3f * fbR;
reverb.process(l, r);
fbL = shifterL.process(l);   // two pt::PitchShifter, setRatio(2.f)
fbR = shifterR.process(r);

Diffuser

#include "pt/fx/diffuser.h" · from Clouds

Smears sound in time without changing its tone: each click becomes a short, dense wash, like the very start of a reverb with no tail. Clouds uses it to blend grains into a texture. It also softens harsh transients, thickens sparse material, and gives a mono source a wide stereo image.

How it works. Four all-pass filters per channel, each a different length. An all-pass passes every frequency at equal level but delays each by a different amount, so together they scatter a transient over a few tens of milliseconds. Left and right use different lengths, which decorrelates them.

CallRangeEffect
init(sampleRate)Allocates the delays.
setAmount(x)0..1Dry/wet mix.
setDiffusion(x)0..1Amount of smearing. Clouds uses 0.625.
process(l, r)In place.
// Turn a dry percussive loop into a soft, wide texture
diffuser.setAmount(params[TEXTURE].getValue());
float l = inputs[IN].getVoltage() / 5.f, r = l;   // mono in, stereo out
diffuser.process(l, r);
outputs[OUT_L].setVoltage(5.f * l);
outputs[OUT_R].setVoltage(5.f * r);

Chorus

#include "pt/fx/chorus.h" · from Rings

A gentle, slow and wide stereo chorus.

How it works. The input goes into a delay line read by four heads 15–30 ms back. Each head is swept by a slow LFO (0.2 Hz and 0.26 Hz, in sine and cosine phases). A delayed copy whose delay keeps changing is slightly detuned, and mixing it with the dry signal thickens the sound. Left and right use different heads and phases.

CallRangeEffect
init(sampleRate)Allocates the delay.
setAmount(x)0..1Wet amount. The dry level drops by half the wet amount.
setDepth(x)0..1Sweep depth, up to ±8 ms.
process(l, r)In place.
pt::Chorus chorus;
// onSampleRateChange: chorus.init(e.sampleRate);

chorus.setAmount(params[MIX].getValue());
chorus.setDepth(params[DEPTH].getValue());
float l = inputs[IN_L].getVoltage() / 5.f;
float r = inputs[IN_R].getNormalVoltage(inputs[IN_L].getVoltage()) / 5.f;
chorus.process(l, r);
outputs[OUT_L].setVoltage(5.f * l);
outputs[OUT_R].setVoltage(5.f * r);

Ensemble

#include "pt/fx/ensemble.h" · from Rings

The lush, shimmering chorus of 1970s string machines such as the Solina and the ARP String Ensemble. Put it after a saw or pulse oscillator, or a divide-down organ, for instant string pads.

How it works. Three delay taps per side, their modulation spread 120° apart, each swept by a slow (0.75 Hz) and a fast (6.6 Hz) LFO together. Because the three taps are at different phases, some always go sharp while others go flat: the sound thickens while its average pitch stays steady.

CallRangeEffect
init(sampleRate)Allocates the delays.
setAmount(x)0..1Wet amount. The dry level drops by half the wet amount.
setDepth(x)0..1Modulation depth, up to about ±3 ms.
process(l, r)In place.
// String machine: a saw into the ensemble
ensemble.setAmount(1.f);
ensemble.setDepth(0.6f);
float l = saw, r = saw;            // saw: any saw oscillator's output
ensemble.process(l, r);
outputs[OUT_L].setVoltage(5.f * l);
outputs[OUT_R].setVoltage(5.f * r);

PitchShifter

#include "pt/fx/pitch_shifter.h" · from Clouds

Shifts audio up or down by any ratio in real time, with a slightly grainy "tape-splice" character.

How it works. The input is written into a short delay line, and a read head moves along it at a different speed from the writer: faster reading raises the pitch, slower lowers it, as with varispeed tape. The read head soon runs into the writer, so there are two heads half a window apart, each faded in and out by a triangle. One is always playing while the other jumps back, which hides the jumps.

CallRangeEffect
init(sampleRate)Allocates the delay.
setRatio(r)0.25..4Pitch ratio: 2 is up an octave, 0.5 down an octave. Use pt::semitonesToRatio().
setSize(x)0..1Window length, about 4 to 64 ms. Short windows follow transients but buzz; long ones are smoother but smear. Changes are smoothed.
process(in)Mono. Use one instance per channel for stereo.
pt::PitchShifter shifter;
// onSampleRateChange: shifter.init(e.sampleRate);

// Transpose knob of ±24 semitones, plus a V/Oct input
float semitones = params[TRANSPOSE].getValue() + 12.f * inputs[VOCT].getVoltage();
shifter.setRatio(pt::semitonesToRatio(semitones));
shifter.setSize(params[WINDOW].getValue());
float in = inputs[IN].getVoltage() / 5.f;
float mix = params[MIX].getValue();
outputs[OUT].setVoltage(5.f * pt::crossfade(in, shifter.process(in), mix));

Overdrive

#include "pt/fx/overdrive.h" · from Plaits

Soft-clipping distortion with built-in level compensation: more drive adds grit and sustain without the output getting much louder. Plaits uses it on its kick drum.

How it works. The signal is boosted into a smooth clipper, then turned back down. The boost stays gentle for most of the knob and climbs to about 24× at the top. The cut is the inverse of how loud a full-scale signal comes out of the clipper. Drive changes are smoothed over about 1 ms.

CallRangeEffect
init(sampleRate)Sets the smoothing time.
setDrive(x)0..10 gives gentle warmth at about unity gain; 1 is heavily clipped.
process(in)Mono; returns the driven signal.
pt::Overdrive drive;
// onSampleRateChange: drive.init(e.sampleRate);

float amount = pt::clamp(params[DRIVE].getValue() + inputs[DRIVE_CV].getVoltage() / 10.f, 0.f, 1.f);
drive.setDrive(amount);
outputs[OUT].setVoltage(5.f * drive.process(inputs[IN].getVoltage() / 5.f));

Wavefolder

#include "pt/fx/wavefolder.h" · from Plaits' waveshaping engine

West Coast-style waveshaping: as the input is driven harder, its peaks fold back on themselves, adding bright, shifting harmonics. There are two curves:

  • process(): a smooth sine-based fold, bright and bell-like. This is Plaits' main output.
  • analog(): a model of an analog folder circuit (five op-amp stages and a diode, in the style of the Buchla 259), rougher and more vocal. This is Plaits' AUX output.

How it works. The input, scaled by the fold amount, reads a transfer curve. The curve is nearly straight at the centre and wiggles further out, so pushing the signal outwards turns each peak into extra wiggles, which are extra harmonics.

Aliasing: folding creates harmonics far above the input's own. Feed it smooth signals such as sine, triangle or a filtered saw, and lower the amount at high pitches; Plaits does this automatically.

CallRangeEffect
init()Builds the curves (once, shared by all instances).
setAmount(x)0..1Fold amount.
process(in)in ±1Returns the smooth fold; analog() then holds the analog fold of the same sample.
pt::Wavefolder folder;
MyModule() { folder.init(); }   // in the module constructor

// A sine (or triangle) into the folder; FOLD knob plus CV
float sine = std::sin(2.f * M_PI * phase);   // phase: your oscillator's 0..1 phase
folder.setAmount(pt::clamp(params[FOLD].getValue() + inputs[FOLD_CV].getVoltage() / 10.f, 0.f, 1.f));
outputs[OUT].setVoltage(5.f * folder.process(sine));
outputs[ANALOG].setVoltage(5.f * folder.analog());

Decimator

#include "pt/fx/decimator.h" · from Plaits

The lo-fi crunch of old samplers and game consoles: the signal is sampled and held at a lower rate.

How it works. A clock ticks at the target rate; at each tick the input is captured and held. Done naively, the steps land on whole host samples and add harsh aliasing that changes with the host rate. Here each step is placed at its exact fractional time and its edge smoothed with PolyBLEP, so you get the intended stair-step sound, the same at any host rate. It adds one sample of latency while active, and passes the signal straight through at or above the host rate.

CallRangeEffect
init(sampleRate)Resets.
setRate(hz)HzTarget sample rate. 2–8 kHz sounds crunchy; a few hundred Hz is extreme.
process(in)Mono.
pt::Decimator crush;
// onSampleRateChange: crush.init(e.sampleRate);

// Knob sweeps the rate exponentially from 200 Hz to 20 kHz
float rate = 200.f * std::pow(100.f, params[RATE].getValue());
crush.setRate(rate);
outputs[OUT].setVoltage(5.f * crush.process(inputs[IN].getVoltage() / 5.f));

Limiter

#include "pt/fx/limiter.h" · from Rings and Warps

Keeps a signal within full scale smoothly, without hard clipping. Put it last in anything that can get loud: resonators, feedback patches, stacked voices.

How it works. A peak follower rises fast (about 0.5 ms) and falls slowly (about 1 s), so the gain doesn't pump on each waveform cycle. Above full scale, the gain becomes 1/peak. A soft clipper then rounds off transients the follower is too slow to catch. In stereo, both channels share one gain, which also watches the left-right difference, so the stereo image holds steady.

CallRangeEffect
init(sampleRate)Resets the follower.
setPreGain(g)1+Gain before limiting. Raise it to make quiet material louder; peaks are caught.
process(in)Mono.
process(l, r)Stereo, in place, linked gain.
pt::Limiter limiter;
// onSampleRateChange: limiter.init(e.sampleRate);

// Final stage of a stereo voice: never exceeds ±5 V
limiter.setPreGain(1.f + 3.f * params[LOUDNESS].getValue());
float l = voiceL, r = voiceR;
limiter.process(l, r);
outputs[OUT_L].setVoltage(5.f * l);
outputs[OUT_R].setVoltage(5.f * r);

FxEngine

#include "pt/fx/fx_engine.h" · from Rings, Elements and Clouds

The toolkit the reverb, diffuser, chorus, ensemble and pitch shifter are built with. Use it to design your own delay-network effects.

How it works. All delay lines live in one circular buffer with a single write pointer that moves one step per sample, so every line advances at once. Each sample you run a short "program" that works like a tiny DSP chip:

  • An accumulator holds the signal being built.
  • You read values into it, filter it, and write it into delay lines.
  • Two slow LFOs are built in for modulating reads.
CallEffect
reset(), addDelay(length), allocate()Setup, in init: declare lines (sized from the sample rate), then allocate. addDelay returns a FxEngine::Delay handle.
setLfoFrequency(i, f)LFO i (0 or 1) at f = Hz / sampleRate.
start()Begin a sample: advance the lines, clear the accumulator.
load(v), read(v, scale)acc = v; acc += v·scale.
write(float& v, scale)v = acc, then acc ×= scale.
read(line, offset, scale), readTail(line, scale)acc += line[offset]·scale; the tail is the oldest sample.
write(line, scale), write(line, offset, scale)line[offset] = acc, then acc ×= scale.
writeAllPass(line, scale)After readTail(line, g), writeAllPass(line, -g) completes an all-pass filter.
interpolate(line, offset, scale)Fractional read.
interpolate(line, offset, lfo, amplitude, scale)Fractional read with the offset swept by an LFO.
lp(state, c), hp(state, c)One-pole filter on the accumulator.
clear()Silence all lines.
// A ping-pong delay with a damped, diffused feedback path
struct PingPong {
    pt::FxEngine e;
    pt::FxEngine::Delay left, right, diffuse;
    float damp = 0.f;

    void init(float sr) {
        e.reset();
        left = e.addDelay(int(sr * 0.25f));     // 250 ms
        right = e.addDelay(int(sr * 0.25f));
        diffuse = e.addDelay(int(sr * 0.007f)); // 7 ms all-pass
        e.allocate();
    }

    void process(float in, float feedback, float& outL, float& outR) {
        e.start();
        // Left line: input plus feedback from the right, smeared and damped
        e.read(in);
        e.readTail(right, feedback);
        e.readTail(diffuse, 0.5f);
        e.writeAllPass(diffuse, -0.5f);
        e.lp(damp, 0.3f);
        e.write(left, 0.f);
        // Right line: fed only by the left, so echoes alternate sides
        e.readTail(left, 1.f);
        e.write(right, 0.f);
        // Outputs: the far end of each line
        e.readTail(left, 1.f);
        e.write(outL, 0.f);
        e.readTail(right, 1.f);
        e.write(outR, 0.f);
    }
};
