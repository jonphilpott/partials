Dynamics

Components that shape level and tone over time: gates, vactrols, compression and envelope following.

LowPassGate

#include "pt/dynamics/lpg.h" · from Plaits

A combined VCA and low-pass filter driven by a model of a vactrol. As a note decays it gets quieter and darker together, the soft "bongo" sound of West Coast synthesis. The envelope is built in: ping it with a trigger, or drive it with a level CV.

How it works. A vactrol is an LED shining on a light-dependent resistor. It responds fast when the light comes on and slowly, with a long tail, when it goes off. The model has one internal state that rises quickly and falls with that same slowing tail, and the state drives three things:

  • the gain;
  • the filter cutoff, which falls faster than the gain because it follows the state to the 4th power;
  • an "HF bleed" of unfiltered signal, which sets how bright the attack is.
CallRangeEffect
setDecay(x)0..1Decay after a ping or a falling level, from a click to several seconds.
setColour(x)0..10 behaves mostly like a VCA. Higher values give more filtering, a brighter attack and some bleed.
setAttackPitch(hz)HzPing attack speed. Plaits ties it to the note so higher notes snap open faster; pass your oscillator's frequency. Default C4.
trigger()Ping: open quickly, then decay.
process(in)Ping mode: returns the gated signal.
process(in, level)level 0..1Level mode: the gate follows the CV through the vactrol response, like patching Plaits' LEVEL input.

Cost: one filter per sample. The envelope updates 4000 times a second, and the gain is ramped smoothly between updates.

// A complete LPG module: trigger pings it; a LEVEL cable switches to CV control
pt::LowPassGate lpg;
dsp::SchmittTrigger trig;

void onSampleRateChange(const SampleRateChangeEvent& e) override { lpg.init(e.sampleRate); }

void process(const ProcessArgs& args) override {
    lpg.setDecay(params[DECAY].getValue());
    lpg.setColour(params[COLOUR].getValue());
    float in = inputs[IN].getVoltage() / 5.f;
    float out;
    if (inputs[LEVEL].isConnected()) {
        out = lpg.process(in, pt::clamp(inputs[LEVEL].getVoltage() / 10.f, 0.f, 1.f));
    } else {
        if (trig.process(inputs[TRIG].getVoltage())) lpg.trigger();
        out = lpg.process(in);
    }
    outputs[OUT].setVoltage(5.f * out);
}
// After a voice (osc is any oscillator): tie the attack to the note, as Plaits does
float hz = pt::voltToHz(inputs[VOCT].getVoltage());
osc.setFrequency(hz);
lpg.setAttackPitch(hz);
if (trig.process(inputs[TRIG].getVoltage())) lpg.trigger();
outputs[OUT].setVoltage(5.f * lpg.process(osc.process()));

Vactrol

#include "pt/dynamics/vactrol.h" · from Streams

A detailed model of a vactrol (an LED shining on a light-dependent resistor), the part behind Buchla-style low-pass gates. Unlike LowPassGate, it doesn't process audio. It turns a control signal into the gain and cutoff a real vactrol would give, and you wire those to your own VCA and filter.

What it models.

  • Saturating response: an S-shaped curve from light to gain, so the cell snaps open quickly, then has a long, soft tail.
  • Second-order lag, with a little overshoot on fast rises.
  • Memory: a cell that has been lit a lot becomes more sensitive and reacts faster, then recovers over about a minute.
  • Plucked mode: each rising edge of the input "plucks" the cell for a repeatable percussive decay.

Streams did this in fixed point; this port is float, with times in seconds.

CallEffect
init(sampleRate)Resets the cell, including its memory.
setAttack(s), setDecay(s)Response times in seconds. Streams' range: attack 10–500 ms, decay 50 ms–5 s. Because of the saturating curve, the gain opens much faster than the attack time suggests.
setPlucked(on)Off: follow the control level. On: each rising edge (above 0.1) plucks.
process(control)Control 0..1 is the light (1 is fully lit). Returns the gain, 0..1.
gain(), cutoff()The latest gain, and the matching cutoff (0..1) to map onto your filter.
// A complete vactrol low-pass gate: Vactrol drives an Svf and a VCA
pt::Vactrol vactrol;
pt::Svf filter;
// onSampleRateChange: vactrol.init(e.sampleRate); filter.init(e.sampleRate);

vactrol.setDecay(0.05f + 2.f * params[DECAY].getValue());
vactrol.setPlucked(params[PLUCK].getValue() > 0.5f);
float gain = vactrol.process(inputs[CV].getVoltage() / 10.f);
float cutoffHz = 50.f * std::pow(300.f, vactrol.cutoff());   // 50 Hz to 15 kHz
filter.setFrequency(cutoffHz, 0.6f);
float in = inputs[IN].getVoltage() / 5.f;
outputs[OUT].setVoltage(5.f * gain * filter.process(in).lp);

Compressor

#include "pt/dynamics/compressor.h" · from Streams

A feed-forward compressor with optional sidechain, soft knee and makeup gain.

How it works.

  1. The level is measured as power (the signal squared), smoothed with separate attack and release times. That tracks the RMS level rather than every peak, which sounds more natural.
  2. In decibels: above the threshold, each dB the input rises gives only 1/ratio dB at the output.
  3. The soft knee rounds the corner at the threshold.

Streams did the maths in fixed-point logarithms to drive an analog VCA; this port works in float dB. With a fast attack the detector follows peaks more closely, which is Streams' default behaviour.

CallEffect
setThreshold(db)Level where compression starts; 0 dB is full scale. Streams: −30 to 0.
setRatio(r)1 (none) to 25+ (limiting).
setAttack(s), setRelease(s)Seconds. Streams' presets: 0.2 ms / 150 ms (hard knee) and 2 ms / 70 ms (soft knee).
setMakeup(db), setSoftKnee(on)Output gain; rounded knee.
process(in), process(in, sidechain)Returns the compressed signal; the second form detects the level from another signal.
gainReduction()Current reduction in dB, for a meter.
pt::Compressor comp;   // onSampleRateChange: comp.init(e.sampleRate);

comp.setThreshold(-30.f + 30.f * params[THRESHOLD].getValue());
comp.setRatio(1.f + 19.f * params[RATIO].getValue());
comp.setAttack(0.002f);
comp.setRelease(0.1f);
comp.setMakeup(params[MAKEUP].getValue() * 12.f);
float in = inputs[IN].getVoltage() / 5.f;
float out = inputs[SIDECHAIN].isConnected()
    ? comp.process(in, inputs[SIDECHAIN].getVoltage() / 5.f)   // ducking
    : comp.process(in);
outputs[OUT].setVoltage(5.f * out);
lights[REDUCTION].setBrightness(comp.gainReduction() / 12.f);

Follower

#include "pt/dynamics/follower.h" · from Rings

An envelope follower that also tracks brightness. Feed it audio, and it outputs two smooth control signals: how loud the audio is, and how bright it is (its "spectral centroid"). Rings uses it so its FM voice follows the dynamics of the input.

How it works. Two filters split the input into low, mid and high bands (at about 160 Hz and 1.6 kHz). Each band has its own envelope detector, faster for higher bands. The envelope is their sum. The brightness is a weighted average of which band dominates, from 0 (all low) to 1 (all high), smoothed with a fast rise and a slow fall.

CallEffect
init(sampleRate, lowHz = 8, lowMidHz = 160, midHighHz = 1600)The slowest detector rate and the two crossovers.
process(in)Returns the envelope (about 0..1 for a full-scale input).
envelope(), centroid()The latest envelope and brightness (0..1).
pt::Follower follower;   // onSampleRateChange: follower.init(e.sampleRate);

float env = follower.process(inputs[IN].getVoltage() / 5.f);
outputs[ENVELOPE].setVoltage(10.f * pt::clamp(env, 0.f, 1.f));
outputs[BRIGHTNESS].setVoltage(10.f * follower.centroid());
