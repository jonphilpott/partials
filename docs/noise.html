Noise

Random sources from Plaits: crackle, stepped noise, smooth wander and resonant particles.

For plain white noise, use pt::Random: rng.bipolar(). Every source here has seed(s) for repeatable output.

Dust

#include "pt/noise/dust.h" · from Plaits

Sparse random impulses with random heights, arriving at an average rate. Low densities give vinyl crackle or rain; high densities give hiss. It is also a good exciter for the resonators.

How it works. Each sample, a random number u (0..1) is drawn. If u is below the chance of an impulse in one sample (density ÷ sample rate), the output is an impulse of height u ÷ that chance; otherwise it is silent.

CallEffect
setDensity(hz)Average impulses per second.
process()An impulse (0..1) or 0.
// Crackle into a modal resonator: random "rain" on a metal plate
dust.setDensity(std::pow(10.f, 3.f * params[DENSITY].getValue()));   // 1 to 1000 Hz
float in = dust.process() * 0.5f;
outputs[OUT].setVoltage(5.f * resonator.process(in));

ClockedNoise

#include "pt/noise/clocked_noise.h" · from Plaits

Sample-and-hold noise: random values held for one clock period each. Low rates give stepped "computer" noise, middle rates a pitched, crunchy buzz, and high rates white noise.

How it works. A phase accumulator ticks at the rate, and each tick holds a new random value. Each step is placed at its exact position between samples and smoothed with PolyBLEP, so the result is pitched rather than aliased. Near and above a quarter of the sample rate it fades into white noise. Sync restarts the clock.

CallEffect
setFrequency(hz)New values per second.
process(sync = false)Returns ±1; sync draws a new value at once.
// Pitched digital noise, sync-able from a trigger
dsp::SchmittTrigger sync;
noise.setFrequency(pt::voltToHz(inputs[VOCT].getVoltage() + 2.f));
bool s = sync.process(inputs[SYNC].getVoltage(), 0.1f, 1.f);
outputs[OUT].setVoltage(5.f * noise.process(s));

SmoothRandom

#include "pt/noise/smooth_random.h" · from Plaits

A smoothly wandering random signal: a random LFO. At each tick it picks a new random target (±1) and glides there along an S-curve, so there are no corners. Use it for vibrato that never repeats, drifting filters, or random panning.

CallEffect
setFrequency(hz)New targets per second.
process()Returns ±1.
// Subtle analog-style pitch drift: ±10 cents, wandering at 0.5 Hz
drift.setFrequency(0.5f);
float cents = 10.f * drift.process();
osc.setFrequency(hz * pt::semitonesToRatio(cents / 100.f));

Particle

#include "pt/noise/particle.h" · from Plaits

Random impulses, each ringing a resonant filter tuned to a random pitch around a centre frequency. Low densities give droplets, pings or a Geiger counter; high densities, a shimmering cloud. Plaits' particle engine sums several and adds a diffuser.

How it works. Each impulse retunes the band-pass filter to the centre frequency shifted randomly by up to ±spread semitones, then rings it. The level is compensated for Q and density, so the loudness stays steady. Unlike Plaits, which retunes at most once per 12-sample block, this version retunes on every impulse.

CallEffect
setDensity(hz)Average impulses per second.
setFrequency(hz), setSpread(semitones)Centre pitch and random detune range.
setQ(q)1 gives soft clicks; 100 and above, long pings.
trigger()Fire an impulse now.
process()The ringing output; impulse() then holds the raw impulse.
// A Plaits-style particle cloud: three particles into a diffuser
pt::Particle particles[3];
pt::Diffuser diffuser;
// onSampleRateChange: init each, and diffuser.init(e.sampleRate)

float hz = pt::voltToHz(inputs[VOCT].getVoltage());
float sum = 0.f;
for (auto& p : particles) {
    p.setDensity(10.f + 2000.f * params[DENSITY].getValue());
    p.setFrequency(hz);
    p.setSpread(24.f * params[SPREAD].getValue());
    p.setQ(1.f + 200.f * params[RES].getValue());
    sum += p.process();
}
float l = sum / 3.f, r = l;
diffuser.process(l, r);
outputs[OUT_L].setVoltage(5.f * l);
outputs[OUT_R].setVoltage(5.f * r);
