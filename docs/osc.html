Oscillators

Plaits' distinctive oscillators, with their raw controls exposed rather than hidden behind three macro knobs.

All of them are anti-aliased: jumps and restarts are corrected with PolyBLEP, which adds one sample of latency. Outputs are about ±1. For plain saw, square and triangle waves, see BasicOscillator.

The common pattern for a pitched oscillator:

void onSampleRateChange(const SampleRateChangeEvent& e) override { osc.init(e.sampleRate); }

void process(const ProcessArgs& args) override {
    float hz = ml::voltToHz(params[PITCH].getValue() + inputs[VOCT].getVoltage());
    osc.setFrequency(hz);   // or setCarrierFrequency for the formant family
    outputs[OUT].setVoltage(5.f * osc.process());
}

VariableShapeOscillator

#include "ml/osc/variable_shape.h" · from Plaits

One oscillator that morphs smoothly from triangle to saw to square, with variable pulse width and optional hard sync. Plaits' virtual-analog workhorse.

How it works. The waveform is a blend of saw, square and triangle computed from one phase. Each shape's jumps and corners get a PolyBLEP correction weighted by its share of the blend, so every in-between shape is alias-free. With sync, a master phase restarts the oscillator each cycle, and the jump at the restart is corrected too.

CallEffect
setFrequency(hz)Pitch. With sync, this is the synced pitch; sweep it for the classic sync sound.
setSyncFrequency(hz)Hard sync to this rate; 0 turns sync off.
setShape(x)0 triangle, 0.5 saw, 1 square.
setPulseWidth(x)0..1: the square's width and the triangle's peak position.
// A sync lead: the master follows V/Oct, the SYNC knob sweeps the slave up
float hz = ml::voltToHz(inputs[VOCT].getVoltage());
vs.setSyncFrequency(hz);
vs.setFrequency(hz * std::pow(2.f, 3.f * params[SYNC].getValue()));   // up to 3 octaves
vs.setShape(params[SHAPE].getValue());
vs.setPulseWidth(0.5f + 0.4f * inputs[PWM].getVoltage() / 5.f);
outputs[OUT].setVoltage(5.f * vs.process());

FormantOscillator

#include "ml/osc/formant.h" · from Plaits

A sine at the "formant" frequency, restarted at the pitch ("carrier") frequency. You hear the carrier's pitch with a spectral peak at the formant: a vocal or nasal tone, and sweeping the formant sounds like a filter sweep with no filter.

CallEffect
setCarrierFrequency(hz)Pitch.
setFormantFrequency(hz)Spectral peak; usually above the pitch.
setPhaseShift(x)Phase offset of the formant sine (cycles), changing the waveform at each restart.
float hz = ml::voltToHz(inputs[VOCT].getVoltage());
formant.setCarrierFrequency(hz);
// The FORMANT knob covers 4 octaves above the pitch, so it tracks the note
formant.setFormantFrequency(hz * std::pow(2.f, 4.f * params[FORMANT].getValue()));
outputs[OUT].setVoltage(5.f * formant.process());

ZOscillator

#include "ml/osc/z_osc.h" · from Plaits

A resonant, filter-sweep-like tone in the style of the Casio CZ synths' resonance waveforms. A formant sine restarts twice per cycle and is faded by a window, so it sounds like a resonant filter being struck once per cycle. Sweeping the formant sweeps the "cutoff".

CallEffect
setCarrierFrequency(hz)Pitch (up to an eighth of the sample rate).
setFormantFrequency(hz)The "resonance" frequency.
setShape(x)0..1: below 0.5 narrows the window, above shifts its phase.
setMode(x)0..1 in three bands: three CZ-like window and offset styles.
float hz = ml::voltToHz(inputs[VOCT].getVoltage());
z.setCarrierFrequency(hz);
z.setFormantFrequency(hz * (1.f + 15.f * params[RESONANCE].getValue()));
z.setShape(params[SHAPE].getValue());
z.setMode(params[MODE].getValue());
outputs[OUT].setVoltage(5.f * z.process());

VosimOscillator

#include "ml/osc/vosim.h" · from Plaits

VOSIM ("VOice SIMulation"), a 1970s technique for vowel-like sounds. Two formant sines restart every pitch cycle and fade under a cosine window. The pitch comes from the restart rate and the vowel colour from the two formants, much as a voice has two main resonances.

CallEffect
setCarrierFrequency(hz)Pitch.
setFormantFrequencies(hz1, hz2)The two formants. Vowels: first 300–900 Hz, second 900–2500 Hz.
setShape(x)Starting phase of the bursts, from smooth (0) to buzzy (1).
// Vowel morph: interpolate formant pairs from "oo" (300, 870) to "ah" (730, 1090) to "ee" (270, 2290)
float v = params[VOWEL].getValue() * 2.f;
float f1 = v < 1.f ? ml::crossfade(300.f, 730.f, v) : ml::crossfade(730.f, 270.f, v - 1.f);
float f2 = v < 1.f ? ml::crossfade(870.f, 1090.f, v) : ml::crossfade(1090.f, 2290.f, v - 1.f);
vosim.setCarrierFrequency(ml::voltToHz(inputs[VOCT].getVoltage()));
vosim.setFormantFrequencies(f1, f2);
outputs[OUT].setVoltage(5.f * vosim.process());

GrainletOscillator

#include "ml/osc/grainlet.h" · from Plaits

A stream of tiny grains, one per pitch cycle: a formant sine shaped by a window that morphs from a short blip to a long bell. Sounds range from glassy and percussive to round and vocal. bleed lets the window itself through, adding body.

CallEffect
setCarrierFrequency(hz)Pitch (up to an eighth of the sample rate).
setFormantFrequency(hz)Grain frequency.
setShape(x)0..1: short blip, then a skewed bell, then a long smooth bell.
setBleed(x)0..1 and above: how much of the window is heard.
float hz = ml::voltToHz(inputs[VOCT].getVoltage());
grainlet.setCarrierFrequency(hz);
grainlet.setFormantFrequency(hz * std::pow(2.f, 5.f * params[GRAIN].getValue()));
grainlet.setShape(params[SHAPE].getValue());
grainlet.setBleed(params[BLEED].getValue());
outputs[OUT].setVoltage(5.f * grainlet.process());

HarmonicOscillator

#include "ml/osc/harmonic.h" · from Plaits (additive engine)

Additive synthesis: up to 32 harmonics of one pitch, each with its own amplitude. Drive the amplitudes from knobs, CVs or computed spectra such as drawbars, formant peaks or spectral tilts.

How it works. It computes one sine per sample and derives every harmonic from it with the Chebyshev recurrence, at one multiply and one add per harmonic. Harmonics fade as they near Nyquist and are silent above it, so nothing aliases. The harmonics come out with phase offsets, which changes the waveform's shape but not its sound.

CallEffect
setFrequency(hz)Fundamental.
setAmplitude(k, a)Amplitude of harmonic k (1 = fundamental). Keep the sum of amplitudes near 1.
setAmplitudes(array, n)Harmonics 1..n at once.
// A spectral "tilt and comb" voice: TILT shapes the slope; ODD mutes even harmonics
float amps[16];
float tilt = params[TILT].getValue();          // 0 = dark, 1 = bright
float odd = params[ODD].getValue();
float sum = 0.f;
for (int k = 1; k <= 16; ++k) {
    float a = std::pow(float(k), -2.f + 2.f * tilt);
    if (k % 2 == 0) a *= 1.f - odd;
    amps[k - 1] = a;
    sum += a;
}
for (float& a : amps) a /= sum;               // normalise the level
additive.setAmplitudes(amps, 16);
additive.setFrequency(ml::voltToHz(inputs[VOCT].getVoltage()));
outputs[OUT].setVoltage(5.f * additive.process());

StringSynthOscillator

#include "ml/osc/string_synth.h" · from Plaits (string machine and chord engines)

A "divide-down" oscillator, as in string machines and combo organs. One master phase gives saw and square waves at four octaves at once, mixed by a registration, like an organ's stops. Follow it with an Ensemble for the classic string-machine sound. All octaves come from one counter, so they stay perfectly locked; very high notes drop their top registers rather than alias.

CallEffect
setFrequency(hz)Pitch of the lowest octave.
setRegistration(x)0..1: sweeps Plaits' presets, from one saw through fuller saw and saw+square mixes to one square.
setRegistration(float r[7])Your own mix, low to high: saw 1×, square 1×, saw 2×, square 2×, saw 4×, square 4×, saw 8×.
setGain(g)Output level.
// A string machine: divide-down oscillator, low-pass, ensemble
strings.setFrequency(ml::voltToHz(inputs[VOCT].getVoltage()));
strings.setRegistration(params[REGISTRATION].getValue());
filter.setFrequency(3000.f, 0.7f);                 // ml::Svf
float s = filter.process(strings.process()).lp;
float l = s, r = s;
ensemble.process(l, r);                            // ml::Ensemble, amount 1
outputs[OUT_L].setVoltage(5.f * l);
outputs[OUT_R].setVoltage(5.f * r);

WavetableOscillator

#include "ml/osc/wavetable.h" · from Plaits (wavetable engine)

Plays your own single-cycle waveforms, morphing between them, with Plaits' cheap anti-aliasing.

How it works. loadWaves() stores each wave's running sum (its integral) rather than the wave. At play time, the difference between successive reads of the integral gives back the wave averaged over everything the read head skipped since the last sample. That averaging acts as a filter whose width follows the pitch, removing most of the aliasing plain table reads produce. A gentle pitch-tracking low-pass finishes the job.

CallEffect
loadWaves(waves, waveSize, numWaves)Waves stored one after another, all the same length. Each is normalised to ±1. This allocates memory, so call it from the constructor or onSampleRateChange, not process().
setFrequency(hz)Pitch.
setMorph(x)0..1: position across the waves, blending neighbours.
// Build a table of 8 waves at start-up: sine morphing to saw-like
ml::WavetableOscillator wt;
MyModule() {
    const int n = 256, waves = 8;
    std::vector<float> table(n * waves);
    for (int w = 0; w < waves; ++w)
        for (int i = 0; i < n; ++i) {
            float s = 0.f;
            for (int k = 1; k <= 1 + w * 4; ++k)      // more harmonics per wave
                s += std::sin(2.f * M_PI * k * i / n) / k;
            table[w * n + i] = s;
        }
    wt.loadWaves(table.data(), n, waves);
}

void onSampleRateChange(const SampleRateChangeEvent& e) override { wt.init(e.sampleRate); }

void process(const ProcessArgs& args) override {
    wt.setFrequency(ml::voltToHz(inputs[VOCT].getVoltage()));
    wt.setMorph(ml::clamp(params[MORPH].getValue() + inputs[MORPH_CV].getVoltage() / 10.f, 0.f, 1.f));
    outputs[OUT].setVoltage(5.f * wt.process());
}
