Physical models

Resonating objects you excite with a signal: strikes, plucks, noise, breath or any audio.

A physical model is two parts: an exciter that puts energy in, and a resonator that rings. The exciter decides the attack (a soft mallet, a hard pick, a bow); the resonator decides pitch, tone and decay.

  • Resonators: ModalResonator and String.
  • Exciters: the Plucker, or any short sound such as a click, a burst of noise, a drum hit, or audio from another module.
  • Both in one: the Tube is excited by breath noise.

Two tips apply to all of them:

  • Resonator outputs can carry a little DC. Follow them with a DcBlocker.
  • Use zero-mean excitation. Noise, a click followed by its negative, or the Plucker all work; a one-sided pulse leaves an offset that rings away slowly.

ModalResonator

#include "ml/physical/modal_resonator.h" · from Rings, with Elements' bowed modes

The sound of a struck or bowed object (a string, a wooden or metal bar, a plate, a bell or a glass), made from up to 64 tuned band-pass filters. It is the core of Rings' modal mode.

How it works. Real objects vibrate in several patterns at once, called modes, each at its own frequency and each decaying at its own rate. Here each mode is one resonant filter:

  • structure sets where the partials sit. A string's are evenly spaced (harmonic); a bar's stretch further apart; a bell's crowd together.
  • damping sets how long everything rings.
  • brightness sets how much faster the high modes die.
  • position mimics where the object is struck. Striking a string in the middle can't excite modes that have a still point (node) there, so even harmonics vanish at 0.5.
SetterRangeEffect
setFrequency(hz)HzFundamental pitch.
setStructure(x)0..1Below 0.25 bell-like; 0.25–0.3 harmonic string; higher values stiffer bars and plates; near 1 metallic.
setBrightness(x)0..1How long high partials ring compared with low ones.
setDamping(x)0..1Overall decay, from a thud (0) to about 30 seconds (1).
setPosition(x)0..1Strike point; 0.5 is the middle.
setModes(n)1..64Number of modes. Fewer is cheaper and plainer; 1 gives a pure resonant filter.
setBowedModes(on)boolAdds Elements' 8 bowed waveguide modes, driven by the second argument of process(). Off by default.
setSideLfo(hz, offset)Hz, 0..1The slow pickup sweep behind side(). Default 0.5 Hz and 0.1.
OutputMeaning
process(in, bow = 0)Returns the sum of all modes. in is the excitation; bow (0..1) is the bow pressure when bowed modes are on.
odd(), even()Odd- and even-numbered modes separately, as on Rings' two outputs. Panned left and right they give a wide stereo image.
side()A slowly moving stereo difference signal: use out + side and out − side for left and right.

Cost: one filter per mode per sample, so about 64 filters at full resolution. Coefficients update 2000 times a second, and position changes are ramped to avoid zipper noise. For many voices, lower setModes().

// Struck object: a trigger "hits" it, audio input excites it continuously
ml::ModalResonator res;
ml::DcBlocker dc;
dsp::SchmittTrigger strike;

void onSampleRateChange(const SampleRateChangeEvent& e) override {
    res.init(e.sampleRate);
    dc.init(e.sampleRate);
}

void process(const ProcessArgs& args) override {
    res.setFrequency(ml::voltToHz(params[PITCH].getValue() + inputs[VOCT].getVoltage()));
    res.setStructure(params[STRUCTURE].getValue());
    res.setBrightness(params[BRIGHTNESS].getValue());
    res.setDamping(params[DAMPING].getValue());
    res.setPosition(params[POSITION].getValue());

    float in = inputs[IN].getVoltage() / 5.f;
    if (strike.process(inputs[TRIG].getVoltage())) in += 1.f;   // one-sample click
    res.process(in);

    // Rings-style stereo: odd modes left, even modes right
    outputs[LEFT].setVoltage(5.f * res.odd());
    outputs[RIGHT].setVoltage(5.f * res.even());
}
// Bowed glass: steady bow pressure from a CV, Elements' bowed modes on
// once, in onSampleRateChange: res.init(sr); res.setBowedModes(true);
res.setStructure(0.6f);
res.setDamping(0.9f);
float bow = ml::clamp(inputs[BOW].getVoltage() / 10.f, 0.f, 1.f);
float out = res.process(0.f, bow);
// Polyphonic: one resonator per channel
ml::ModalResonator voices[16];
// onSampleRateChange: for (auto& v : voices) v.init(e.sampleRate);
int channels = std::max(1, inputs[VOCT].getChannels());
for (int c = 0; c < channels; ++c) {
    voices[c].setModes(24);   // cheaper per voice
    voices[c].setFrequency(ml::voltToHz(inputs[VOCT].getPolyVoltage(c)));
    outputs[OUT].setVoltage(5.f * voices[c].process(inputs[IN].getPolyVoltage(c) / 5.f), c);
}
outputs[OUT].setChannels(channels);

String

#include "ml/physical/string.h" · from Elements and Rings

A plucked or struck string using the Karplus-Strong method, extended with dispersion: it covers plain strings, stiff piano-like strings, rattling strings and a buzzing sitar-style bridge.

How it works. A delay line exactly one period long holds the travelling wave. Each trip round the loop, the wave passes through two filters and comes back slightly quieter and duller, so any excitation repeats at the string's pitch and dies away like a real string.

  • damping sets the loop's loss.
  • brightness sets its low-pass.
  • dispersion adds either an all-pass filter, which makes high harmonics travel slower as in a stiff string, or a nonlinear "curved bridge" that buzzes.
SetterRangeEffect
setFrequency(hz)HzPitch. Below about 16 Hz the loop is resampled, which sounds rough.
setDispersion(x)0..10.5 is a plain string. Above it, stiffer and inharmonic, rattling near 1. Below it, a buzzing curved bridge.
setBrightness(x)0..1How quickly high harmonics die.
setDamping(x)0..1Decay time; from 0.95 it fades into infinite sustain.
setPosition(x)0..1Position of the second pickup, read with aux().
process(in)Returns the string output; aux() then holds the second pickup's sample.
seed(s)Seeds the rattle noise, for repeatable output.

Cost: light: one delay line and a few filters. Use it freely for polyphony.

// Plucked string with a trigger input
ml::Plucker pluck;
ml::String string;
dsp::SchmittTrigger trig;

void onSampleRateChange(const SampleRateChangeEvent& e) override {
    pluck.init(e.sampleRate);
    string.init(e.sampleRate);
}

void process(const ProcessArgs& args) override {
    float hz = ml::voltToHz(params[PITCH].getValue() + inputs[VOCT].getVoltage());
    pluck.setFrequency(hz);
    pluck.setCutoff(hz * 16.f);
    string.setFrequency(hz);
    string.setDispersion(params[DISPERSION].getValue());
    string.setBrightness(params[BRIGHTNESS].getValue());
    string.setDamping(params[DAMPING].getValue());
    string.setPosition(params[POSITION].getValue());

    if (trig.process(inputs[TRIG].getVoltage())) pluck.trigger();
    float out = string.process(pluck.process());
    outputs[OUT].setVoltage(5.f * out);
    outputs[PICKUP].setVoltage(5.f * string.aux());
}
// Sympathetic strings: one input, several strings tuned to a chord
// (each init()ed in onSampleRateChange)
ml::String strings[3];
const float intervals[3] = {0.f, 7.f, 12.f};
float out = 0.f;
for (int i = 0; i < 3; ++i) {
    strings[i].setFrequency(hz * ml::semitonesToRatio(intervals[i]));
    strings[i].setDamping(0.9f);
    out += strings[i].process(in * 0.3f);
}

Tube

#include "ml/physical/tube.h" · from Elements

A reed and air column. Blow noise into it and it gives a reedy, clarinet-like tone with mostly odd harmonics.

How it works. A delay line stands in for the air column. At the mouthpiece, a simple reed curve compares the breath pressure with the wave coming back down the tube. The reed opens and chokes in step with that wave, which keeps the oscillation going. The loop's behaviour depends on the sample rate, so the model always runs at Elements' 32 kHz internally and is interpolated to the host rate.

CallRangeEffect
setFrequency(hz)HzSounding pitch.
setDamping(x)0..1Higher values soften and mute the breath.
setTimbre(x)0..1Brightness.
process(breath, envelope)±1, 0..1breath: the air (noise, or noise mixed with audio). envelope: blowing pressure, which also scales the output. Returns the tube sound.

Tips: a little breath noise (±0.1 to ±0.3) gives a natural tone; more sounds airy. The tube only sounds while envelope is above zero, so drive it from an envelope generator or a pressure CV.

ml::Tube tube;
ml::Random rng;
// onSampleRateChange: tube.init(e.sampleRate);

void process(const ProcessArgs& args) override {
    tube.setFrequency(ml::voltToHz(inputs[VOCT].getVoltage()));
    tube.setDamping(params[DAMPING].getValue());
    tube.setTimbre(params[TIMBRE].getValue());
    float breath = params[AIR].getValue() * rng.bipolar();
    float pressure = ml::clamp(inputs[PRESSURE].getVoltage() / 10.f, 0.f, 1.f);
    outputs[OUT].setVoltage(5.f * tube.process(breath, pressure));
}

Plucker

#include "ml/physical/plucker.h" · from Rings

A short burst of noise shaped like a pick or finger: Rings' internal exciter. Feed it into a String or ModalResonator.

How it works. Each trigger() starts a white-noise burst lasting a fraction of one period of the note. The burst then goes through two filters:

  • a feedback comb filter, which shapes the spectrum the way the pluck point along a string does;
  • a low-pass, which sets how bright the pick is.
CallRangeEffect
setFrequency(hz)HzPitch of the note being plucked; sets the burst length. Match it to the resonator.
setCutoff(hz)HzBurst brightness: a few times the note frequency sounds like a finger, 20–30 times like a hard pick.
setPosition(x)0..1Pluck point: low values are near the bridge (bright, thin), high values longer and rounder.
trigger()Start a burst with the current settings.
process()Next sample of the burst (silence between bursts).
seed(s)Seeds the noise, for repeatable bursts.
ml::Plucker pluck;
ml::ModalResonator res;
dsp::SchmittTrigger trig;
// onSampleRateChange: pluck.init(sr); res.init(sr);

void process(const ProcessArgs& args) override {
    float hz = ml::voltToHz(inputs[VOCT].getVoltage());
    float hardness = params[HARDNESS].getValue();          // 0 = finger, 1 = pick
    pluck.setFrequency(hz);
    pluck.setCutoff(hz * (2.f + 30.f * hardness));
    pluck.setPosition(params[POSITION].getValue());
    if (trig.process(inputs[TRIG].getVoltage())) pluck.trigger();

    float burst = pluck.process();
    outputs[EXCITER].setVoltage(5.f * burst);               // useful on its own too
    res.setFrequency(hz);
    outputs[OUT].setVoltage(5.f * res.process(burst));
}
